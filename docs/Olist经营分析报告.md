# Olist 电商经营分析报告（整合版 · 金标准）

> 分析人：祁思源（卿时彧） · AI 协作：DeepSeek / WorkBuddy · 2026-10
> 数据：Kaggle `olistbr/brazilian-ecommerce`（9.9 万真实订单，2016-09 ~ 2018-10）
> 本报告 = P1 质检 + P2 指标体系 + P3 归因 + P4 LLM 增强 的最终整合，也是 Step 2 Agent 输出质量的验收基准

---

## 一、摘要（TL;DR）

1. **业务全景**：平台 2017 年爆发式增长，2017-11 黑五达月 GMV 峰值 115 万；2018 年起进入约 100 万/月的平台期
2. **根因**：获客引擎失速（月新客 2018-01 见顶后 -10%）× 单一收入结构（新客贡献 97%、复购率仅 3.0%）——已用排除法排除品类结构与体验恶化的解释
3. **AI 增强发现**：LLM 读懂 10 万条葡语评论，物流延误是差评第一大主因（35.8%），与统计证据（1 星订单迟到率 37.9%）三角验证闭环
4. **风险预警**：迟到率 2017→2018 从 6.5% 升至 9.3%（承诺管理问题，非履约能力问题）
5. **AI 能力边界**：LLM 情感判断"极端可靠、中间模糊"（1/5 星一致率 93%+，3 星仅 12%），落地应采用置信度路由

## 三、指标体系核心发现（P2）

| 维度 | 关键数字 | 业务含义 |
|------|---------|---------|
| 交易 | 月 GMV 100 万平台期，AOV 稳定 147~170 | 问题不在客单价 |
| 商品 | health_beauty 居首（9.3%），头部集中 | 品类结构健康 |
| 客户 | 复购率 3.0%，RFM 冠军组仅 3,570 人 | 存量贡献 2~3%，增长全靠新客 |
| 地域 | SP 一州占 37.4% | 市场高度集中，物流网络围绕圣保罗 |
| 履约 | 平均 12.6 天，迟到率 8.1% | 巴西物流现实 + 承诺管理隐患 |
| 口碑 | 5 星占 57%+，1 星订单迟到率 37.9% | 低分与"超承诺送达"强相关 |

## 四、归因专题（P3，详见 [P3_归因分析报告](P3_归因分析报告.md)）

**题目：2018 年 GMV 为什么停止增长？**

- 量价拆解：订单量横盘、AOV 稳定 → 问题在获客端
- 维度下钻：2018H1 vs 2017H1 无品类下滑 → 排除结构性恶化
- 假设验证：体验恶化被排除（履约更快、评分稳定）；**获客见顶被证实**（新客曲线 2018-01 顶点 6,842 后回落 -10%）
- 数据陷阱处理：2018-09/10 delivered 缺失 = 采集截尾，非业务崩盘（用下单口径交叉核对）

## 五、AI 增强（P4，详见 [P4_LLM情感分析报告](P4_LLM情感分析报告.md)）

- 分层抽样 1,000 条葡语评论 → DeepSeek 批量情感分类 + 差评归因（1 分 45 秒，成本 <1 元）
- **幻觉验证**：与真实打分交叉对比，总体一致率 70.9%；分档 1星 97% / 5星 93.5% / **3 星 12%** → "极端可靠、中间模糊"，解法 = 置信度路由（极端档自动、中间档人工）
- **负面归因**：物流 35.8% / 质量 35.3% / 卖家 25% —— 与统计证据三角验证闭环

## 六、业务建议（按 ROI 排序）

1. **修复送达承诺算法**：迟到率上行 + 差评第一主因都是物流，一个动作打两个痛点（调整预估送达模型，按州/品类差异化承诺）
2. **提升复购（治本）**：会员体系/召回/交叉销售，目标把存量贡献从 3% 提到 10%+，改变"97% 依赖获客"的脆弱结构
3. **扩大获客漏斗**：新客曲线走平说明现有渠道饱和，开拓新地域/新流量
4. **建立监控**：月度新客数、迟到率进经营看板 + 阈值告警
